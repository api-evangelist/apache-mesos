Great work everyone; Apache Mesos 1.6.0 was released on May 11! New Features and Improvements Mesos 1.6 includes improvements to persistent volumes, usability of the scheduler API, Docker daemon support, and memory allocation performance. Resizing Persistent Volumes Mesos 1.6 adds experimental support for the resizing of persistent volumes .
