The latest Mesos release, 1.4.0, is now available for download . This release includes the following features and improvements: MESOS-5116 - The disk/xfs isolator now supports the --enforce_container_disk_quota flag to efficiently measure disk usage without enforcing usage constraints. The previous implementation always enforced the quota even if the operator might not have wanted it.
