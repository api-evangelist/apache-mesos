The latest Mesos release, 0.25.0, is now available for download . This release includes the following features and improvements: [MESOS-1474] - Experimental support for maintenance primitives. Please refer to the maintenance documentation for more information. [MESOS-2600] - Added master endpoints /reserve and /unreserve for dynamic reservations.
