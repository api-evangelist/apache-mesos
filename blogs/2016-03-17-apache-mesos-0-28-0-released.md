The latest Mesos release, 0.28.0, is now available for download . This release includes the following features and improvements: [MESOS-4343] - A new cgroups isolator for enabling the net_cls subsystem in Linux. The cgroups/net_cls isolator allows operators to provide network performance isolation and network segmentation for containers within a Mesos cluster.
