The latest Mesos release, 0.27.2, is now available for download . This release includes fixes and improvements for the following: MESOS-4693 - Variable shadowing in HookManager::slavePreLaunchDockerHook. MESOS-4711 - Race condition in libevent poll implementation causes crash.
