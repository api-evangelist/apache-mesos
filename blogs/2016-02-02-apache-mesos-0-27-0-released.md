The latest Mesos release, 0.27.0, is now available for download . This release includes the following features and improvements: [MESOS-1791] : Support for resource quota that provides non-revocable resource guarantees without tying reservations to particular Mesos agents. Please refer to the quota documentation for more information. [MESOS-191] : Multiple disk support to allow for disk IO intensive applications to achieve reliable, high performance. [MESOS-4085] : Flexible roles with the introduction of implicit roles .
