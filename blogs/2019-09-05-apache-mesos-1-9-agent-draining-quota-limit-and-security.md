We are excited to announce that Apache Mesos 1.9.0 is now available for download . Please take a look at what’s new in this release! New Features and Improvements Agent Draining Automatic agent draining was added to allow operators to prepare agent nodes for maintenance without requiring schedulers to implement support for the feature.
