The latest Mesos release, 1.1.0, is now available for download . This release includes the following features and improvements: [MESOS-2449] - Experimental support for launching a group of tasks via a new LAUNCH_GROUP Offer operation. Mesos will guarantee that either all tasks or none of the tasks in the group are delivered to the executor.
